# Baseline Evaluation Checklist

Baseline evaluation should include:

- Accuracy and macro F1 for overall comparison.
- Per-class precision and recall for rare fault types.
- Confusion matrix review for labels that operators commonly mix.
- Short-text error cases and noisy ticket examples.
- A note on class imbalance before comparing model variants.

This checklist keeps evaluation connected to maintenance usefulness, not only leaderboard-style metrics.
